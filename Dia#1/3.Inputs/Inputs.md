# Inputs

Sirve para que el usuario ingrese sus propios valores al código con la palabra clave `input`.
![](../../../imgs/8.Inputs.png)

El input almacena un valor directo asignado al usuario para poder usarlo más adelante, pero este mismo también se puede imprimir.
